# Personal-Website
This repository contains all the source code and files for my personal website, built as a [Jekyll](https://jekyllrb.com) site and deployed automatically via GitHub Pages.

I wrote this site to practice my web development programming skills (using css, html, javascript). If you are a _**scientist or researcher**_ and interested in this template, kindly reach out for more information or just adjust the source code!

## Updating content
See [`CONTENT-GUIDE.md`](CONTENT-GUIDE.md) — publications, timeline, blog posts, and the industry news feed are all edited as plain Markdown/YAML files, no HTML editing required.

## Local development
```bash
bundle install
bundle exec jekyll serve
```
Then open http://localhost:4000.
